# PhotoPlus

A lightning-fast app for cropping, compressing, rotating and scaling multiple photos in one go. 
PhotoPlus is a Flutter project that runs on Android, iOS, Windows and macOS devices. No need to 
upload your photos, everything happens offline on your device.

You are welcome to contribute your ideas.
